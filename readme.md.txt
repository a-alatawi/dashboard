# GC Vessel & Cargo Tracker

A real-time vessel tracking system for monitoring inbound, working, and sailed vessels.

## Features
- Add and track vessels with detailed information
- Real-time dashboard with vessel summaries
- Shift scheduling with 8-day rotation
- RORO units tracking
- Responsive design for all devices

## How to Use
1. Open `index.html` in any modern web browser
2. Use Add a Vessel tab to add new vessels
3. Switch to Dashboard to view all vessels
4. Data is saved automatically

## Technologies Used
- HTML5, CSS3, JavaScript
- LocalStorage for data persistence
- Responsive design

## Deployment
This application is deployed on GitHub Pages and uses Firebase for real-time data synchronization.
